Numerical Sieves - Github

I wanted to use haskell to explore various number sieves in simila manner to how you would calculate a sieve by hand.

Objective

I know there are better ways to write sieves in haskell, as most can be written in one line. Additionally, if the goal were to calculate numbers or get a series, writing in a different language is also a good option. However, I wanted to use haskell specific features in a clear and simplistic way for my own exploration.
