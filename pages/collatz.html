Collatz - Github

Coding problem to calculate multiple Collatz sequence lengths in as little time as possible. The Collatz conjecture hypothesizes that for the recursive function: f(x) = f(x/2) for x%2 == 0 | 0 for x == 0 | f(3x+1) otherwise

Methodology

Each single calculation can be done rather quickly, the problem just comes from reduntant calculations. I used a lookup table to store previously calculated values to speed up the process.

Results

The size of the lookup table for optimal performance is widely varried based on the application. Too big and it's a waste of memory for no speedup, too small and it also does nothing.

Technology Used

  • Java
  • Lookup Tables
