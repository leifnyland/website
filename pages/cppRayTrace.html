C++ Ray Tracing - Github

Ray tracing project written in C++.

Objective

I started this project to dust off cobwebs that may have formed since I was in undergrad. I chose the project because I have made a ray tracer before, but I did not like how little of the code I understood. I want to write a ray tracer where I wrote every line of code, and I also think it might be a good platform to teach myself some parallel computing basics.

Methodology

This project is still under development, and I will add images and updates as it progresses.

My next goals include:

  • Better lighting
  • Material properties. Each object should be able to control where it falls on the mirror/eggshell spectrum, and also use objects as light sources
  • Clear materials
  • Triangles/triangle meshes. I'm steering clear of this for the moment because I do not know how I want to represent triangle meshes.
  • Various small aethetic improvements, such as textures, adaptive sampling, etc

Goals completed:

  • Basic camera/scene setup
  • Reflections
  • 4 ray antialiasing
  • Image film can be any ratio
  • Grid antialiasing based on a variable

Results

Fixed some bugs and just generally made sure reflections were looking pretty good.

Added true grid antialiasing by casting in an even grid, size controlled by a variable. No single ray is used more than once.

Added antialiasing by casting rays in the corner of pixels instead of in the middle, then averaging the 4 pixels

First image with reflections, only the white sky is used for lighting.
